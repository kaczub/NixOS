# Glossary

[← Index](../README.en.md) · [Polski](glossary.md) · English

Short explanations of the terms used in the configuration and documentation.
Option and command names stay in English because that is how they appear in
Nix.

| Term | Meaning |
|---|---|
| **flake** | A self-contained Nix configuration with inputs and outputs. Replaces classic channels. |
| **input** | A flake dependency, e.g. `nixpkgs` or `home-manager`. |
| **output** | What a flake exports, e.g. `nixosConfigurations.thinkpad`. |
| **flake.lock** | The file with exact input versions. Do not edit it by hand — `nix flake lock` generates it. |
| **derivation** | A recipe for building a package or file in Nix. |
| **Nix store** | The `/nix/store` directory of immutable artifacts. Paths contain hashes. |
| **generation** | A version of a system or user profile. You can switch back to it. |
| **rollback** | Returning to a previous generation (`nixos-rebuild --rollback`, `darwin-rebuild --rollback`). |
| **Home Manager (HM)** | Declarative management of user files and packages. |
| **nix-darwin** | Nix modules that manage macOS: defaults, services, casks. |
| **activation / switch** | The moment Nix writes the new configuration and runs activation scripts. |
| **cask** | A GUI application installed by Homebrew (e.g. `ghostty`, `brave-browser`). |
| **formula (brew)** | A CLI tool installed by Homebrew (e.g. `gh`, `mpv`). |
| **tap** | An additional Homebrew formula or cask repository. |
| **Brewfile** | A Homebrew package list generated by nix-darwin from `homebrew.casks` and `homebrew.brews`. |
| **Homebrew prefix** | Homebrew's installation directory. Usually `/opt/homebrew` on Apple Silicon. |
| **TCC** | The macOS privacy permission system: camera, microphone, Accessibility, Full Disk Access. |
| **Full Disk Access** | A permission that lets a terminal or `darwin-rebuild` change protected files. |
| **SIP** | System Integrity Protection. Some window managers may require a partial disable. |
| **WM** | Window manager — a program that arranges windows. E.g. niri on Linux. |
| **tiling** | Automatically arranging windows without overlap. |
| **dotfiles** | Configuration files versioned in a repository. Here everything lives in Nix. |
| **declarative** | We describe the desired state instead of a sequence of clicks. |
| **stateVersion** | The version of module defaults. It is not the system version. |
| **GC** | Garbage collection — removing unused paths from the Nix store. |
